LLG 订阅助手 1.0.0

适用于 Windows 10/11 64 位，双击程序即可运行。
GitHub Release 文件名为 LLG-SubscriptionHelper-win-x64.exe；本地打包文件名为 LLG订阅助手.exe。

1. 点击右上角“设置”，填写自己的用户名和密码，点击“保存”。
2. 点击“更新服务器列表”，等待显示“已更新 N 个节点”。
3. 点击“转换为可导入”，等待提示已复制。
4. 切换到 v2rayN 主窗口按 Ctrl+V，或选择“配置项 → 从剪贴板导入分享链接”。

本程序获取 /backend/user/sub 认证接口的第一方列表。
转换支持目前已验证的 VLESS TCP 和 AnyTLS 节点；后续出现未知参数会明确提示，不会静默丢失节点。
建议使用支持 AnyTLS 的 v2rayN，格式基准为 7.24.9。

账号与最近一次成功的列表加密保存在：
%LOCALAPPDATA%\LLG.SubscriptionHelper\state.dat
切换 Windows 用户或换电脑时，请重新填写账号。

导入的是本次更新的节点快照。列表有变化时，重新更新、转换并在 v2rayN 中导入。
分享链接只携带节点连接参数，DNS、策略组和路由规则由 v2rayN 自身设置决定。

更新失败会保留上次成功的列表。更换用户名后，需要重新更新对应账号的列表。
程序不包含预置账号，关闭程序后不保留登录 token。
